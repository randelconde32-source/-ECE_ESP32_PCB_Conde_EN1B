# -ECE_ESP32_PCB_Conde_EN1B

## Project Description

This project presents the design and development of a custom **ESP32 Expansion PCB** for embedded systems and IoT applications. The board is designed to provide a stable power supply, organized GPIO accessibility, and convenient hardware interfacing through a compact and efficient PCB layout.

The PCB integrates an ESP32 development board with onboard power management components, enabling easy connection of sensors, modules, and external devices. The design process includes schematic development, PCB routing, component placement, and 3D verification to ensure reliable electrical performance and mechanical compatibility before fabrication.

## Features

- **ESP32 Development Board Support**  
  Provides a dedicated mounting and expansion platform for ESP32-based projects.

- **GPIO Expansion Headers**  
  Easy access to ESP32 pins for interfacing with sensors, actuators, and communication modules.

- **Integrated Power Regulation**  
  Includes voltage regulation and filtering components for stable operation.

- **Power ON/OFF Toggle Switch**  
  Allows convenient control of the board power supply.

- **DC Barrel Jack Input**  
  Supports external power source connection.

- **Power Status LED**  
  Indicates power availability and board operation.

- **Compact PCB Layout**  
  Efficient arrangement of components for prototyping and educational use.

## Components Used

|---|-----------|-------------|
